# Planner 0.1.0 implementation plan

Use [platform.md](platform.md) for directories, storage and packaging, [workspace.md](workspace.md) for UI and REST contracts, [access-and-mcp.md](access-and-mcp.md) for roles, events and MCP, and [migration.md](migration.md) for the source contract. The five spec deltas define externally observable acceptance. Keep these artifacts at the same approved planning revision in every handoff.

Phase 1 establishes the build and fixture interfaces. Phase 2 can proceed once the application boot contract lands. Phase 3 must establish the data and access boundaries before Phase 4 uses them. Phase 5 needs the approved target entity contracts and Phase 6 needs the operation registry. They can proceed in separate worktrees after those prerequisites are integrated. Phase 7 tests the integrated build. Each checkbox needs its own code, relevant docs and evidence before review.
